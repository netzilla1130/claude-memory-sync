## 2026-05-17 重要经验 — Slate.js auto-scroll 灾害

**视频自动滚动 bug**：Slate 编辑器开启了"follow video"，视频播放时会自动滚动 list 到当前 cue。这导致：
1. 我 triple_click 一个坐标
2. 视频微小时间推进导致 list scroll
3. 我的输入落到错误的 row

**症状**：编辑了 row N，但实际改的是 row N±k

**解决**：
1. `document.querySelector('video').pause()` 不够 — 编辑过程中可能被触发恢复播放
2. 真正稳的做法：每次 triple_click 后立刻 screenshot 验证高亮的是哪一行，再开始打字
3. 编辑顺序：尽量同一 batch 完成所有视觉可见行的编辑（少 scroll），不要跨 scroll 边界连续编辑

**Ctrl+A 在 Slate 内的行为不可靠**：可能只选当前段落，可能选全 cell，可能多余的"全选所有 row"。改用 `triple_click + Delete + type + Enter + type` 这一序列（不要 Ctrl+A）

**Order 10 上发生过的事故**：

- row 39 被清空（restored 为 "Helen."）
