中→英短剧字幕 polish 时，**不要逐字直译，不要为了"补回原文每个字"的微妙语义而改译**。目标是 international audience 易理解，而非忠实复刻每个原文字符。

**Why:** 2026-05-16 给用户做 Order 151171840002 校对时，我提出几处"微调"想补回原文细节：
- 行 32: 她可是你亲姑 → 把 `She's your aunt.` 改成 `She's your own aunt.` 补"亲"语义
- 行 51: 明白明白 → 把 `Understood.` 改成 `Got it, got it.` 模仿叠词
- 行 64: 涨涨租子了 → 把 `a little more.` 改成 `a little more rent.` 补"租"

用户明确拒绝这三处，并强调："不要拘泥于原文，切忌逐字直译，目的是 easier to understand for international audience"。

**How to apply:** Polish 时只动以下情况：
1. 真正的错译（误解原意 / 数学不对 / 角色错位 / 拼写语法错）
2. 格式问题（画面字 `[]` 缺失 / 中括号错位 / 字幕换行）
3. 字符数限制超标（25 字符/行）
4. 用词前后不一致（同一人名/术语跨行不同）
5. 标点导致歧义（如 `Brother, Sophia.` 易读成"叫 Sophia 的哥哥"，改 `Brother. Sophia.`）

**不要动**：当前译文已传达核心意思的句子，即使原文有叠词、加强语气词、修饰词没翻出来，只要英文读着自然且能让国际观众理解剧情，就保留原样。

**文化梗特别注意**：中文文化特有的成语、俗语、亲属称谓、典故等，不要"硬译"（保留中式句法/字面意思），要转化为英文语境里自然的对应表达。例：
- `仁至义尽` → `That's more than fair.`（不要 "kindness exhausted"）
- `一毛都没` → `not a single cent`（不要 "not even one feather"）
- `沾沾喜气` → `to bring her some luck`（不要 "rub the joy"）
- `三姑/大姨` → 用本地化名字 `Aunt Helen`（不要 "Third Aunt"）
- `把钱看那么重` → `be so tight with money`（不要 "see money so heavy"）
- 兄弟姐妹称呼（大哥/三妹）→ 直接用本地化名字或省略，不要 "Big Brother"

**一句话跨多 cue 的标点 / 大小写规则**（重要）：当一个完整句子被切成 2 个或多个字幕 cue（subtitle line），中间所有 cue 末尾**不能加句号**，续行 cue 首字母**不能大写**（除非是专有名词）；只有句子最后一个 cue 才用句号收尾。

✅ 正确：
```
Line 25: The shops around here...
Line 26: have all cut their rent       ← 中间 cue，无句号，无大写
Line 27: by over fifty percent.        ← 末尾 cue，正常标点
```

❌ 错误（不要这样）：
```
Line 26: have all cut their rent.      ← 中间 cue 加了句号
Line 27: By over fifty percent.        ← 续行大写
```

判定方法：看下一行 cue 是否在语法/语义上接续本行。如果接续，本行末尾**去掉句号**，下一行首字母改小写。这条规则适用于：句号、逗号都没必要（中间 cue 一般什么标点都不加），只在最末尾 cue 加完整标点。
